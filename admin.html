How to use with GitHub + Netlify

  1. Put each product photo in assets/products/.
  2. Use the exact image path in the form.
  3. Save products here.
  4. Click Download products.js.
  5. Replace the old products.js in your GitHub repository with the downloaded file and commit it.
  6. Netlify will automatically redeploy the connected site.

Important: this browser-only manager does not directly write to GitHub. A secure GitHub-connected admin panel would need a server/API layer so your GitHub token is never exposed in the browser.
