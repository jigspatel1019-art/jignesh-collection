JIGNESH COLLECTION - ADMIN PANEL

This version lets you add/edit/delete saree, jewellery and accessory products and upload photos from phone or computer. Product data and images use Netlify Blobs.

DEPLOY: Connect this folder to a GitHub repository, then in Netlify choose Add new project -> Import an existing project -> GitHub. The included netlify.toml configures public/ and Netlify Functions.

ADMIN PASSWORD: In Netlify Project configuration -> Environment variables, add ADMIN_PASSWORD with your strong password, then redeploy. Do not put the password in the HTML.

WHATSAPP: In public/index.html change PHONE="919999999999" to your number with 91, no + or spaces.

ADMIN: https://YOUR-SITE.netlify.app/admin.html

FREE URL: Netlify provides a netlify.app address; you can rename the site in Netlify.
